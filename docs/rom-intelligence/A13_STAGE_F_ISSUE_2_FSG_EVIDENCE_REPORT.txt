6. Root cause classification
----------------------------
H1: Default-home gate (HIGH confidence)
  Third-party default home makes mIsUseMiuiHomeAsDefaultHome false; module does
  not override getDefaultHomePackageName or mIsUseMiuiHomeAsDefaultHome; ROM
  therefore does not create gesture stub windows.

H2: REAL_FORCE_FSG_NAV_BAR uninitialized (LOW confidence)
  Opposed by constructor call order and safe null handling.

H3: com.mi.android.globallauncher not routed (LOW confidence)
  Routing gap exists, but not the cause of the third-party default-home issue.

Static classification: UPSTREAM_LIFECYCLE_LIMITATION
Runtime classification: UNVERIFIED
Production corrective required: NO (this batch)
Device verified: NO

10. Recommendation
------------------
No production change in this batch.

To enable horizontal gestures when a third-party launcher is default, a future
production batch would need to override one of:
  - com.miui.home.launcher.common.Utilities.getDefaultHomePackageName()
  - BaseRecentsImpl.mIsUseMiuiHomeAsDefaultHome field
  - BaseRecentsImpl.addFsgGestureWindow() / updateFsgWindowState() branching
Such a change requires dedicated tests and real-device validation before it can
be claimed to resolve Issue #2.
