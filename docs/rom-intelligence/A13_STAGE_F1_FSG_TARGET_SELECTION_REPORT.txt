9. Candidate corrective designs
-------------------------------
Design A: Hook Utilities.getDefaultHomePackageName to return "com.miui.home"
  - Pros: single choke point.
  - Cons: affects FallbackHomeCompat, isUseMiui/PocoHomeAsDefaultHome, settings UI,
          nav-bar dialog and elderly-mode receiver; requires stack walk; high risk.
  - Risk: HIGH.
  - Rank: 4

Design B: Hook BaseRecentsImpl.addFsgGestureWindow + setIsUseMiuiHomeAsDefaultHome
  - addFsgGestureWindow after-hook: force mIsUseMiuiHomeAsDefaultHome = true and
    re-call updateUseLauncherRecentsAndFsGesture() / updateFsgWindowState().
  - setIsUseMiuiHomeAsDefaultHome before-hook: override p3 to true when
    controls_fsg_horiz and REAL_FORCE_FSG_NAV_BAR are both true.
  - Pros: localized to BaseRecentsImpl; does not touch settings UI or Utilities;
          preserves REAL_FORCE_FSG_NAV_BAR fail-closed; reuses existing
          updateFsgWindowState() for stub management; naturally writes
          use_gesture_version_three true.
  - Cons: may keep re-triggering observer updates; could decouple
          mIsUseMiuiHomeAsDefaultHome from OverviewComponentObserver.mIsHomeAndOverviewSame.
  - Risk: MEDIUM.
  - Rank: 1 (RECOMMENDED)

Design C: Hook only addFsgGestureWindow / updateFsgWindowState branch logic
  - Force stub-creation branch regardless of mIsUseMiuiHomeAsDefaultHome.
  - Pros: small logic change.
  - Cons: use_gesture_version_three may remain false; mIsUseMiuiHomeAsDefaultHome
          still false for other consumers and for later observer-driven removal.
  - Risk: MEDIUM-HIGH.
  - Rank: 3

Design D: Hook OverviewComponentObserver.updateOverviewTargets
  - Force mIsHomeAndOverviewSame = true and setIsUseMiuiHomeAsDefaultHome(true).
  - Pros: covers the observer path.
  - Cons: changes mOverviewIntent category/component and home intent construction;
          may force MIUI recents when third-party launcher is default.
  - Risk: HIGH.
  - Rank: 4

11. Conclusion
--------------
Stage F1 static analysis is complete. The default-home gate is the only
statically demonstrated blocker for horizontal FSG when a third-party launcher
is the default. The recommended design (B) is to hook `BaseRecentsImpl.
addFsgGestureWindow()` and `BaseRecentsImpl.setIsUseMiuiHomeAsDefaultHome()`
while preserving the `REAL_FORCE_FSG_NAV_BAR` fail-closed channel.

No production change has been made in this batch.
Issue #2 remains UNVERIFIED at device level.
Production change requires an explicit corrective gate and real-device validation.
