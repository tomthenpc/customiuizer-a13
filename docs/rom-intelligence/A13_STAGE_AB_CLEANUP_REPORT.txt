Tool Storage Hardening
----------------------

The following tools were updated to use temporary workdirs and clean up by
default. The `--keep-workdir` flag is an explicit opt-in only.

1. tools/rom_part_extractor.py
   - Added `estimate_partition_size()` and `_check_disk_space()`.
   - Added `--keep-workdir` and temporary-workdir default.
   - When `--out` / `--out-dir` are omitted, extracted files are written to a
     temporary directory and removed on exit.
   - For `--all`, the same temp/cleanup logic applies unless an output
     directory is specified.
   - Prints the estimated extracted size before writing.

2. tools/rom_apk_extract.py
   - Rewritten as a high-level pipeline:
     super.img (or partition.img) -> temporary partition -> extract APK ->
     compute SHA-256 -> write requested output -> delete temp partition.
   - Supports both super images (with `--partition`) and existing partition
     images.
   - `--keep-workdir` retains the intermediate partition for debugging.
   - Performs disk-space checks for both the temp partition and the output.

3. tools/rom_super_inspector.py
   - Already uses `tempfile.TemporaryDirectory` and only unsparses the first
     8 MiB for liblp metadata. No large file is written by default.

4. tools/rom_fs_probe.py
   - Only reads the first few KiB of a partition image. No temp files.
   - Fixed in-file EROFS magic documentation.

5. tools/rom_dex_inspector.py
   - Parses the APK/DEX in memory. No intermediate files.
