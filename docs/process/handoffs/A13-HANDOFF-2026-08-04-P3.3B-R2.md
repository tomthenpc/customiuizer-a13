## 3. Key implementation

### 3.1 Source contract parser

Added read-only `tools/legacy_exception_source_contract.py`:

- `extract_function_body(text, func_name, language)` using balanced-brace extraction.
- `parse_boolean_expression(expr)` to decompose top-level `&&`/`||` chains.
- `get_enclosing_if_condition(source, call_pos)` to locate the `if` surrounding a call.
- `derive_setup_global_actions_activation()` from `SystemServerInstaller.needGlobalActions()`.
- `derive_setup_foreground_monitor_activation()` and `derive_setup_foreground_monitor_call_site_conditions()` from `SystemUiInstaller.install()` and `GlobalActions.setupForegroundMonitor()`.
- `derive_alarm_compat_activation()` / `derive_runtime_config_keys()` from `Various.AlarmCompatServiceHook()`.

### 3.2 Schema v4 and runtimeConfigKeys

- `schemaVersion` 3 -> 4.
- New optional record field `runtimeConfigKeys`.
- `AlarmCompatServiceHook` marks `various_alarmcompat_apps` as runtime config.
- Bidirectional invariant: `preferenceKeys == sorted(fixedActivationKeys ∪ callConditionKeys ∪ runtimeKeys)`.
- P3.3A records are not forced to carry new fields; validator allows missing `runtimeConfigKeys`/`activationContract`/`callSiteConditions`.

### 3.3 Validator fail-closed

- Non-dict `activationContract` returns `INVALID_ACTIVATION_CONTRACT` instead of crashing.
- `thresholdExclusive` must be a strict `int` (rejects `bool`, `float`, `str`, `None`).
- Exact `allowed`/`required` field sets per mode/kind.
- Unknown fields, duplicate predicates, empty predicate lists, unsorted lists, `UNCONDITIONAL` with predicates are rejected.
- `callSiteConditions` predicates must canonical-match an `activationContract` predicate; otherwise `CALL_SITE_CONDITION_NOT_ACTIVATION_BRANCH`.
