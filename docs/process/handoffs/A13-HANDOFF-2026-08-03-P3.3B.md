Each record contains the v2 fields plus two optional but validated machine contracts:

```json
{
  "id": "stableUniqueId",

  "phase": "SYSTEM_SERVER_STARTING|PACKAGE_READY|RESOURCE_INIT|BOOTSTRAP|OTHER",
  "preferenceKeys": [],
  "activationContract": {
    "mode": "UNCONDITIONAL|ANY_OF",
    "predicates": [{"kind": "...", "...": "..."}]
  },
  "callSiteConditions": {
    "sourceFile:line:function": {"kind": "...", "...": "..."}
  },
  "reasonCode": "controlled enum",
  "reason": "specific technical explanation",
  "coveredCallSites": [],
  "hookTargets": [],
  "testEvidence": [],
  "exitCondition": "specific condition for migration or removal"
}
```

### `preferenceKeys` semantics

`preferenceKeys` only lists the fixed literal preference keys that the exception route or feature logic directly references. Dynamic key domains (such as all keys ending with `_action`) are expressed in `activationContract` and must not be enumerated in `preferenceKeys`.

### `activationContract` semantics

`activationContract` is a closed, machine-validated structure. Allowed modes: `UNCONDITIONAL`, `ANY_OF`. Allowed predicate kinds: `BOOLEAN_KEY_TRUE`, `INT_KEY_GT`, `DYNAMIC_SUFFIX_INT_GT`, `FIXED_INT_ANY_GT_AND_NONEMPTY_SET`. Free-form text expressions are not allowed.
