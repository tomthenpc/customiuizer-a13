## 3. Key implementation

### 3.1 Independent truth architecture

三层严格分离：

- **Generator consistency**（仅 `P3_3B_GeneratorConsistencyTest`）：唯一允许调用 `build_registry()`，仅验证生成器与 committed JSON 一致，不作为 truth。
- **Source contract truth**（`P3_3B_LegacyExceptionRouteTest`、`IndependentTruthTest`、`P3_3B_SourceMutationTest`）：expected 只能来自 `tools/legacy_exception_source_contract.py` 的 `derive_*()` 入口。
- **Schema mutation**（`P3_3B_ActivationContractMutationTest`）：对 `self.committed` 副本直接 mutation + `builder.validate()` 或 `canonical_diff()`，不通过 `build_registry()`。

### 3.2 Source contract parser fail-closed

- `_find_function_definition` 现在区分 declaration 与 call，跳过注释/字符串中的伪声明，检测到多个候选、Kotlin expression body、overload 时抛出 `SourceStructureError`。
- `_extract_all_if_blocks` 跳过字符串/注释中的 `if` token。
- `_extract_return_in_block` 使用 `_find_top_level_returns` 保证只在顶层 if body 中查找。
- 删除未使用的 `_match_action_predicate` 与 `_expr_char_state`。
- `derive_setup_foreground_monitor_activation` 与 `derive_alarm_compat_activation` 改用 `_extract_preference_keys` 精确匹配 key，避免子字符串误配。

### 3.3 Source mutation tests use final `derive_*()` entry points

`P3_3B_SourceMutationTest`、`SetupGlobalActionsMutationTest`、`ForegroundMonitorMutationTest`、`AlarmCompatMutationTest` 全部通过临时 `SOURCE_ROOT` override 调用最终 `derive_*()` 入口，验证 mutation 导致 `SourceContractError` 或 contract 改变，而不是仅检查中间 parser 结构。

### 3.4 Completion evidence gate

新增 `tools/tests/test_p33b_completion_evidence.py`：机械核对 `TASK_STATE.md` 中记录的三个 focused test counts 与 `discover` 总数，与实际 `unittest` loader 计数一致。

### 3.5 Registry provenance

`docs/audit/A13_LEGACY_EXCEPTION_REGISTRY.json` 已从当前 baseline `33ce1ab5969d61c94c0ce3f7942c8dac02a5c579` 重新生成；`sourceCommit` 指向 build 输入 HEAD；`sourceTree` 与 `inputDigest` 稳定；仅 `generatedAt` 与 `generatorVersion` 可变。
