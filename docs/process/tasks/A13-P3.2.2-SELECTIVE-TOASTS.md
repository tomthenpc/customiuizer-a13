## Original behavior

`SystemServerInstaller.install` checks `MainModule.mPrefs.getStringAsInt("system_blocktoasts", 1) > 1` and, when true, directly calls `SystemStatusBarAndClockHooks.SelectiveToastsHook(lpparam)`. The hook is not registered in `FeatureCatalog`, `FeatureInstallRegistry`, or `CatalogContracts`.

## Invariants

Behavior that must remain unchanged:

- The hook is installed on `com.android.server.notification.NotificationManagerService.tryShowToast` using `hookAllMethods`.
- `system_blocktoasts` preference default and activation threshold (`> 1`) remain the same.
- Disabled path installs no hook.
- The `SelectiveToastsHook` code body (filtering logic) is unchanged.

Behavior that must change:

- A typed `FeatureId` and `FeatureCatalog.specs()` entry must exist for `selectiveToasts`.
- A `DiagnosticIds` entry must exist.
- A `CatalogContracts.selectiveToasts` contract must describe the hook target.
- `SystemServerInstaller` must call `FeatureDispatcher.installById("selectiveToasts", serverRuntime)` instead of the direct method call.

Forbidden behavior:

- Leaving the legacy direct call in `SystemServerInstaller` after migration.
- Changing the hook method or class to match the contract incorrectly.
- Adding the feature without a contract or diagnostic ID.

## Independent oracle

Main/release differential:

- The release APK uses `ModuleHelper.hookAllMethods` on `com.android.server.notification.NotificationManagerService.tryShowToast` when `system_blocktoasts > 1`.

Focused behavior test:

- `FeatureIdentityCompletenessTest` confirms `selectiveToasts` is in `FeatureCatalog`, `FeatureId`, and `DiagnosticIds` with no conflicts.

Callback/integration test:

- `SystemServerInstaller` installs `selectiveToasts` via `FeatureDispatcher` when the preference is enabled.

Contract test:

- `CatalogContracts.selectiveToasts` matches `SystemStatusBarAndClockHooks.SelectiveToastsHook` production call.
- `tools/check_hook_contract_parity.py` continues to pass for batch 12.

ABI test:

- No change to `app/src/main/**` public API surface beyond the new catalog entries.

Mutation cases:

- remove `FeatureCatalog` spec: focused test fails;
- remove `CatalogContracts.selectiveToasts`: contract parity fails;
- keep direct `SystemServerInstaller` call and also add dispatcher: orphan direct-call path.
