## Independent truth architecture

三层严格分离：

- **Generator consistency**（仅 `P3_3B_GeneratorConsistencyTest`）：允许 `build_registry()`，仅验证生成器与 committed JSON 一致，不作为 truth。
- **Source contract truth**（`P3_3B_LegacyExceptionRouteTest`、`IndependentTruthTest`、`P3_3B_SourceMutationTest`）：expected 只能来自 `tools/legacy_exception_source_contract.py` 的 `derive_*()` 入口。
- **Schema mutation**（`P3_3B_ActivationContractMutationTest`）：对 `self.committed` 副本直接 mutation + `builder.validate()` 或 `canonical_diff()`，不通过 `build_registry()`。

## Test ownership boundaries

- `test_p33b_legacy_exception_routes.py`：route 与 source-truth 测试。
- `test_legacy_exception_source_contract.py`：parser 单元与三向 independent truth。
- `test_p33b_completion_evidence.py`：completion evidence 数字机械核对。
- `P3_3B_GeneratorConsistencyTest`：唯一允许 `build_registry()`。

## Source parser fail-closed boundary

- 必须命中 declaration，不能命中 call。
- Java declaration 与 Kotlin block-body declaration 使用明确正则/前缀模式。
- 多个同名候选、Kotlin expression body、overload 无法唯一确定时抛 `SourceContractError`。
- 注释/字符串中的函数样式、调用行、字符串/注释中的 braces 不得误导解析。
- 不支持的新形态显式失败，不静默误解析。
