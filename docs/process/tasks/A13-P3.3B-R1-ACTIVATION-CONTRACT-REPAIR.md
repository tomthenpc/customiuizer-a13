## Single objective

## Schema v3 design

### Top level

```json
{
  "schemaVersion": 3,
  "inputDigest": "...",
  "totalLegacyCallSites": 514,
  "totalLegacyGroups": 205,
  "firstBatchSize": 4,
  "registeredRecordCount": 8,
  "batchCounts": {"P3.3A": 4, "P3.3B": 4},
  "records": []
}
```

### Record fields

保留 v2 全部字段，新增：

- `activationContract` (optional but validated)
- `callSiteConditions` (optional but validated)

### `activationContract` schema

```json
{
  "mode": "ANY_OF",
  "predicates": [
    {"kind": "...", "...": "..."}
  ]
}
```

Allowed `mode`:

- `UNCONDITIONAL`
- `ANY_OF`

Allowed `kind`:

- `BOOLEAN_KEY_TRUE`
- `INT_KEY_GT`
- `DYNAMIC_SUFFIX_INT_GT`
- `FIXED_INT_ANY_GT_AND_NONEMPTY_SET`

每个 predicate 必须包含 `kind` 和该 kind 的必填字段；不允许任意字符串或自由表达式。

### `callSiteConditions` schema

```json
{
  "<stable-call-id>": {
    "kind": "INT_KEY_GT",
    "key": "various_showcallui",
    "thresholdExclusive": 0
  }
}
```

- key 必须属于该 record 的 `coveredCallSites`。
- 使用的 `key` 必须存在于该 record 的 `preferenceKeys`（若该 kind 需要 key）。
- 未列入的 calls 使用 record-level `activationContract`。

## preferenceKeys 正式语义

`preferenceKeys` 只保存该 exception route 或功能逻辑中直接引用的、具有稳定具体名称的 preference keys。动态 key domain 不得通过手工枚举伪装成完整列表；动态 domain 必须放入 `activationContract`。固定 literal key 必须出现在 `preferenceKeys`。不存在的 key、类型不匹配且不会触发 route 的 key 不得加入。

## setupGlobalActions repair

- `preferenceKeys` 仅保留固定 literal keys:
  - `controls_volumemedia_down`
  - `controls_volumemedia_up`
  - `controls_mediaplayer_apps`
- 移除所有手工枚举的 `_action` keys（包括 `system_cc_custom_clock_action` 等）。
- `activationContract`:
  - `ANY_OF`
  - predicate 1: `DYNAMIC_SUFFIX_INT_GT`，`keySuffix=_action`，`thresholdExclusive=1`，`valueType=INTEGER`
  - predicate 2: `FIXED_INT_ANY_GT_AND_NONEMPTY_SET`，`integerKeys=["controls_volumemedia_up","controls_volumemedia_down"]`，`thresholdExclusive=0`，`requiredNonEmptySetKey=controls_mediaplayer_apps`
- `reason` 明确动态 suffix predicate、Integer type guard、media branch 复合条件、以及 `preferenceKeys` 只保存固定 literal keys。

- route/preference/target 的 expected 必须从生产 installer/function 源码、committed registry、或固定 schema 契约独立解析。
