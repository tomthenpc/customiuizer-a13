# r13.2.3-test1 Pre-release

> ⚠️ 这是测试版 Pre-release，仅用于 MIUI 14 / Android 13 实机验证，不推送到 Xposed-Modules-Repo，也不标记为 stable release。

## 适用环境

- MIUI 14 / Android 13
- ABI：`arm64-v8a`
- libxposed：API 101 基线 / target API 102
- Application ID：`tv.withaibuild.customiuizer.r13`

## 主要变更

### 工程对齐
- `docs/LSPOSED_FULL_LOG_REVIEW_PROTOCOL.md`：动态 LSPosed 完整日志审查协议。

### 性能与生命周期
- `PrefPair`：新增无 Regex 分隔解析工具，替代 `toRegex()` 的 `split("\\|")` 调用。
- `SystemUI`：状态栏文本图标改用 `WeakReference` 注册，防止旧 `View`/`Context` 被静态集合长期强引用。

### 构建配置
- 升级 Gradle cache：`org.gradle.configuration-cache=true`、`org.gradle.caching=true`。
- `release`/`develop` 签名缺失时 fail-fast。
- 统一 APK 输出名为 `CustoMIUIzer-A13-<versionName>.apk`。

## 验证

- `:app:test`：57 个单元测试通过。
- `:app:lint` / `:app:lintRelease` / `:app:lintVitalRelease` 通过。
- `:app:assembleDebug` / `:app:assembleDevelop` / `:app:assembleRelease` 通过。
- Release APK：v2 签名、R8 混淆、resource shrink、zipalign 对齐。
- `module.prop` / `scope.list` / `java_init.list` 元数据正确。
- 无 legacy Xposed API 引用。

## 安装与回滚

- 在 LSPosed 中启用模块，scope 选择默认推荐的应用列表。
- 如遇到问题，可回退到上一个稳定版，并上传 LSPosed 完整日志到本 Release 讨论区。
