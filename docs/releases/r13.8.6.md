# r13.8.6

## 版本定位

A13 最新维护分支合并后的正式版本，面向 MIUI 14 / Android 13。版本号更新为 `131 / r13.8.6`。

## 主要变化

* 将 A13 最新维护、Catalog、兼容诊断、作用域与 UI 修复统一合并到 `main`；
* 完善功能目录、进程目标、重启要求、Hook 目标解析和安装结果诊断；
* 加强 Receiver、Observer、Step Counter、设备监控和锁屏专辑图生命周期；
* 减少状态栏、通知、网速、电池、时钟和 Launcher 高频路径中的重复分配；
* 状态栏网速保留系统字体家族，并支持双排网速行距调整；
* 修复设置文本样式继承和 About 页面文字换行；
* 统一版本元数据、README、CHANGELOG 和发布流程。
