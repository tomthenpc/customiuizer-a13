# r13.7.0 (English)

CustoMIUIzer A13 formal stable release for MIUI 14 / Android 13.

## Highlights

- Completed the System, SystemUI, and Launcher domain split and Kotlin migration, protected by a migration audit for Hook order, arguments, and invocation counts.
- Added exception isolation and explicit ownership for receivers, observers, listeners, handlers, and runnables registered by Hooks.
- Fixed RemotePreferences initialization, listener state, mirror recovery, and additional-instance-field lifetime handling.
- Bounded caching, scheduling, and cancellation for device monitoring, application icons, settings search, AudioVisualizer, and lock-screen album art.
- Retained the API 101 minimum runtime path with no Legacy Xposed API.

## Device-log result

The LSPosed 2.1.1 (7790) export `LSPosed_20260730_112137` contains no module-causal crash, ANR, Fatal, Hook/reflection failure, RemotePreferences anomaly, or repeated exception. The three historical ANRs belong to YouTube broadcasts, while all 17 tombstones belong to audio services, AyuGram, or old `libksud` processes.

The module has no unconditional positive load message, so the generic analyzer did not match a `loaded` line. LSPosed database, scope, and injection snapshots provide the load evidence for SystemUI, Launcher, and related system processes.
