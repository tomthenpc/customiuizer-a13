# CustoMIUIzer A13 r13.9.2

面向 MIUI 14 / Android 13 与 HyperOS 1 / Android 13 的正式版本。

## 核心变化

- 锁屏专辑图所属 View 脱离后释放模块背景、单帧缓存和静态处理结果，降低 SystemUI 大 Bitmap 的驻留时间；
- 页面切换动画按 A14 当前实现恢复为 350ms，改善过快的导航节奏；
- 开关复用父行按压状态获得即时反馈，移除逐次透明度动画及其临时渲染状态；
- LSPosed 模块列表使用独立简洁摘要，不再把完整 README 展开为一长串文字；
- 未改变 MIUI 14 / Android 13 与 HyperOS 1 / Android 13 的 ROM Hook 目标、Contract 或 fallback。
