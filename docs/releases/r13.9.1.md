# CustoMIUIzer A13 r13.9.1

面向 MIUI 14 / Android 13 与 HyperOS 1 / Android 13 的正式版本。

## 核心变化

- Contract、Resolver 与 installer 使用同一 ClassLoader 和原子 target variant，增强 ROM 差异诊断，拒绝猜测式 fallback；
- 修复 ResourceHooks getter 参数展开和状态栏时钟安装诊断闭环；
- 保持普通异常按功能隔离，同时确保直接或包装的 `OutOfMemoryError` 不被吞掉；
- 加固 Receiver、Preference、计步器、设备监控、AudioVisualizer、锁屏专辑图、电池指示器和延迟输入事件的生命周期；
- 减少状态栏、通知、控制动作、Launcher 与资源替换热路径的反射和临时分配；
- 缩短设置页面动画，使 Preference 和开关点击更快显示反馈，并清理离开界面后的延迟事件。
