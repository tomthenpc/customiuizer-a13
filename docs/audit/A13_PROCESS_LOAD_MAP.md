### A13-PERF-FINDING-010 — SystemUI 强制 `Application#onCreate` Hook

- **位置**：`SystemUiInstaller.install` 无条件 Hook `com.android.systemui.SystemUIApplication#onCreate`
- **进程**：`SYSTEM_UI`
- **证据**：<ref_snippet file="C:\Users\tv\Downloads\Peengeek\customiuizer-a13-forDevin\app\src\main\java\tv\withaibuild\customiuizer\installers\SystemUiInstaller.java" lines="59-70" />
- **静态风险**：SystemUI 启动时即注册并执行回调，回调内加载 `SystemUIStatusBarHooks`、`GlobalActions`，注册偏好监听器。即使所有功能关闭，该 Hook 仍存在。
- **需要的运行时证据**：`systemui_cold_start` 对比 `systemui_home_idle` 的增量 PSS。

### A13-PERF-FINDING-011 — Launcher 强制 `Application#attach` Hook

- **位置**：`LauncherInstaller.installApplication` 无条件 Hook `Application#attach`
- **进程**：`LAUNCHER`

## 6. 禁止类加载检查项

P1A 未修改源码，仅记录以下待验证/优化项：

1. 普通应用进程是否会加载 `SystemUIStatusBarHooks`、`LauncherGestureHooks` 等无关类。
2. 功能关闭时 `Controls.kt`、`Various.kt`、`GlobalActions.kt` 是否仍然被触发类初始化。
3. 包名/进程名过滤是否在功能类初始化之前发生。
4. `MainModule.onPackageReady` 中是否先构建完整 installer list 再逐项判断（目前是 `if (scope == ...)` 分支，未构建 list）。
5. Kotlin `object` / `companion object` 是否在各自 installer 调用前发生静态初始化。
6. 同一偏好键是否被多个 installer 重复读取。
