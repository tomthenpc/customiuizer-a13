## 有效变更矩阵（CHG-01 .. CHG-11）

### CHG-01：按进程路由的安装架构

- **覆盖符号**：`MainModule`、`PackageInstallerRouter`、`SystemServerInstaller`、`SystemUiInstaller`、`LauncherInstaller`、普通应用 `Installer`。
- **关键事实**：新增 `ProcessScope` 与 `ProcessScopes.resolve()` 作为包/进程路由唯一来源；`MainModule.onPackageReady()` 移除 `Application.attach` 与 `mPrefs.get*` 调用，改由 `ProcessScope` 分发到 `AndroidPackageInstaller`、`SystemUiInstaller`、`LauncherInstaller`、`SettingsInstaller`、`SecurityCenterInstaller`、`PowerKeeperInstaller`、`WallpaperInstaller`、`MediaInstaller`、`PhoneInstaller`、`PackageInstallerRouter`、`InputMethodInstaller`、`GenericAppInstaller` 等独立 Installer。
- **用户影响**：SystemUI、Launcher、system_server 与普通应用入口按目标进程拆分；避免无关进程加载不属于自己的安装路径与偏好初始化。
- **最终证据**：`ProcessScope.kt:10-38`（enum + `isInstallable`），`ProcessScope.kt:89-135`（`resolve` / `shouldLoadPrefs` / `shouldHook`），`MainModule.java:88-166`（按 scope 分发），`installers/*.java`（新增/修改 13 个）。
- **测试**：`test_process_scope.py`、`test_process_scope_table.py`、`test_main_module_routing.py`、单元测试。
- **置信度**：High

### CHG-02：Feature 注册与安装状态

- **覆盖符号**：`FeatureCatalog`、`CatalogContracts`、`FeatureInstallRegistry`、`FeatureIdentity`、`FeatureSpec`、`FeatureDispatcher`、`ProcessScope`、`InstallPhase`。
- **关键事实**：新增 `FeatureCatalog`（静态类型化 `FeatureSpec` 目录）、`FeatureInstallRegistry`（进程级安装注册表，含 id 归一化、别名冲突检查、原子 `INSTALLING` 申领、兼容政策、状态诊断）、`CatalogContracts`、`FeatureDispatcher`、`InstallPhase` 等；大批功能迁移到注册表。
- **用户影响**：使用稳定 Feature 身份、进程范围与安装阶段；防止重复安装；不兼容或缺失目标时只跳过受影响功能；关闭功能减少无关注册和对象创建。
- **最终证据**：`FeatureCatalog.kt`（大量 `FeatureSpec`）、`FeatureInstallRegistry.kt:32-355`（register / installById / 原子 claim / 兼容检查）、`CatalogContracts.kt`、`FeatureIdentity.kt`、`FeatureSpec.kt`、`FeatureDispatcher.kt`、`InstallPhase.kt`、相关类型。
- **测试**：`FeatureInstallRegistryTest.kt`、`FeatureCatalogTest.kt`、`CatalogBatch1/2/3/9And10ContractTest.kt`、`FeatureIdentityCompletenessTest.kt`、Python 合同测试。
- **置信度**：High

### CHG-03：偏好加载与启动状态

- **覆盖符号**：`PreferenceLoadRegistry`、`early preference snapshot`、`needLoadPrefs`、`empty snapshot`、`concurrent bootstrap`、`installed` / `installing` / `failed` state。
- **关键事实**：从 `MainModule` 提取 `PreferenceLoadRegistry`，集中处理 `various_alarmcompat`、`system_statusbarcolor`、`system_nooverscroll`、`controls_volumemedia` 四个遗留规则的加载判断，保持原 `||` 短路和异常语义；注册表维护 `installed` / `installing` / `failed` 状态，避免空快照与并发竞争导致重复安装和错误状态回退。
- **用户影响**：加固启动早期偏好快照和并发加载；避免空快照、失败状态或偏好更新导致重复安装和错误状态回退。
- **最终证据**：`PreferenceLoadRegistry.kt:41-132`、`MainModule.java:99-100`、`FeatureInstallRegistry.kt` 状态机。
- **测试**：`PreferenceLoadRegistryTest.kt`、`test_main_module_routing.py`。
- **置信度**：High

### CHG-04：MIUI 14 / HyperOS 1 兼容探测

- **覆盖符号**：`ROM environment`、`Contract`、`Resolver`、`variant selection`、`CompatibilityPolicy`、`diagnostics`。
